🎛️ sloop-fm1 - Turn Your FM-1 Into a Live Groovebox

sloop-fm1 is a live groovebox firmware for the M-VAVE FM-1. It gives you a hands-on way to build beats, layer loops, and perform patterns on the fly, instead of browsing menus between takes. You do not need to write code, install developer tools, or understand firmware jargon. If you can plug in a USB cable and open a downloaded file, you can run sloop-fm1.

This page walks you through the whole process from start to finish: getting the software, preparing your device, running it for the first time, and fixing the small snags that occasionally appear on Windows.

🎚️ What You Can Do With sloop-fm1

sloop-fm1 is built around performing rather than pausing to set things up. The main things you can do once it is running:

  • Launch patterns live. Trigger patterns on the fly and switch between them while the groove keeps moving, without stopping playback.
  • Build loops step by step. Add a part, listen, and add the next one. Layers stay in time with each other.
  • Shape the sound as you play. Adjust tone and movement during a session so the same pattern does not sound flat twice.
  • Save your work. Keep the patterns you like so you can return to them next time instead of starting over.
  • Sync with your other gear. Keep sloop-fm1 in step with the rest of your setup so everything plays together.
  • Work without a computer. After setup, the FM-1 runs on its own. Your laptop is only needed for getting sloop-fm1 onto the device.

Because sloop-fm1 is a firmware, it lives on the device itself. That means fewer cables, fewer windows on screen, and more time with your hands on the hardware.

🛠️ Quick Fixes for Common Snags

Almost every problem people run into has a simple answer. Try these before anything else.

The download will not start

Refresh the releases page and try again. If you are on a work or school network, it may block downloads from unfamiliar sites; try a home connection or a different browser.

Windows says the file is unsafe

Click More info, then Run anyway. This is a standard warning for files that have been downloaded only a few times. You can also right-click the downloaded file, open Properties, and tick the Unblock box at the bottom.

The FM-1 is not recognised

Unplug the cable and try a different USB port, ideally one directly on the computer rather than through a hub. Swap the cable if you have another one, since some cables only carry power and cannot pass data. Then power the device off and on again.

The application closes right away

Restart your computer and open the file again. Make sure the download finished completely; a partial download will not run.

Everything runs but there is no sound

Check that the volume on the FM-1 is turned up, that your headphones or speakers are firmly connected, and that the correct output is selected. Then try a different pattern to rule out an empty one.

🤝 Where to Get Help

If something does not work after trying the fixes above, open the project page at the sloop-fm1 releases page and look at the issues section. Someone has very likely asked the same question already. If not, start a new issue and describe three things: your Windows version, what you were doing when the problem appeared, and the exact wording of any message you saw. Those three details usually lead to an answer quickly.

When you report a problem, mention that you are running sloop-fm1 on the M-VAVE FM-1 and include the version number shown on the release you downloaded. That helps others reproduce what you are seeing and point you to the right fix.
